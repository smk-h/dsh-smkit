本文说明 dsh-smkit 的「主题中心」：在「设置 → 通用」里提供 One Dark Pro 配色与 VS Code 式的分区卡片工作台。

## 一、 主题与色系

「设置 → 通用」页里的「主题中心」行内置 1 款主题配色：One Dark Pro：

- **交给宿主去画**：一款主题是一张 `--dsw-*` 令牌表，应用时作为宿主的覆盖层（`ctx.theme.overrideTokens`）叠在当前主题之上，同时把宿主的偏好钉到这款主题所绘的色系（`colorScheme: light` / `dark`）。令牌由宿主的呈现层写成内联变量，`data-ds-dark-theme` 与 `color-scheme` 也跟着这个偏好走，主题没点名的令牌一律由宿主按同一色系补齐——所以主题不可能再和宿主对「现在是哪一半」产生分歧，也不会出现「深色主题配浅色浮层」这类错位。
- **一款主题一个色系**：主题自己声明所绘的色系，这里没有昼夜开关——应用主题时会把宿主的偏好钉到该色系，这也是刷新后配色能原样回来的原因；在「设置 → 通用」的外观行改到别的色系，即视为退出本主题，颜色层撤下、选择清空，由宿主的配色接管。「恢复默认」把手上的偏好交还给「跟随系统」。

## 二、 卡片工作台

标题右侧的复选框把界面切成「VS Code 现代界面」那种分区卡片——左栏、会话区、右栏各自成为带圆角与描边的独立面板，面板之间留出 8px 间隙。画布与面板**同色**，分区只靠各自 1px 的描边和这段留白读出（这也是它参照的那套编辑器边框的做法），所以会话区四周不会出现一圈底色不同的边带。开关只往 body 挂一个 `data-smkit-workbench="card"` 属性，样式表按它限定作用域，取消勾选即整块失效、界面回到宿主原样。样式读的是宿主布局包自己的 `data-shell-overlay` / `data-rightbar-col` 挂点，而不是那些随构建变化的哈希类名，所以宿主换版本也不会错位；右栏收起（轨道宽度为 0）时不画这一块。

- **卡片之间的拖动条**：宿主的分隔条按列边界居中摆放，卡片化之后正好压到面板边缘上，于是只能贴着边线抓。这张皮把它整个平移进新开出的间隙里，并在间隙中央点三个点作标记：鼠标移进间隙时画出一条贯穿全高的细竖线，按住即可拖动，两侧间隙都是如此。线宽 6px、两端圆角取半宽 3px，位置与颜色则跟卡片边框同源——走 `border-l1`，在 One Dark Pro 下两边都是 `#3e4452`。这条线一度用过文字色阶（二级灰 `#9da5b4`），结果成了整屏最亮的东西；主题的 `brand-primary` 同样不能用，它是「主按钮底色」这类表面色，浅色主题下近黑、深色主题下近白。三个点只在悬停前显示，作为「这里可以拖」的提示，竖线一出现它们就让位——VSCode 的分隔条上只有线、没有点，两者不同时出现。

## 三、 状态与编程接口

- **选择只存在浏览器里**：选中哪款主题记在 localStorage 的 `smkit:theme` 上（宿主的偏好存储只收 `light` / `dark` / `system`，认不出我们的主题 id），卡片工作台记在 `smkit:workbench`，调色板的编辑记在 `smkit:theme-colors`。刷新或重开页面即恢复；不写 dsh 的 `settings.yaml`，不落任何服务端文件，也不随工作区走。
- **编程接口**：插件挂载时把同一套状态暴露为 `window.smkitTheme`（`list` / `get` / `set` / `reset` / `cycle`），控制台里就能换肤、轮播，效果与点卡片完全等价；`setMode` / `getMode` 随昼夜开关一起去掉了。

> [!NOTE]
> 配色取自 One Dark Pro 官方源码的主题文件（`themes/OneDark-Pro.json`，[Binaryify/OneDark-Pro](https://github.com/Binaryify/OneDark-Pro)），逐项映射到 DSH 的语义令牌，不做主观润色——包括那几处最容易凭印象写错的：徽标与强调是 `#4d78cc`，光标才是 `#528bff`，链接和语法里的函数是 `#61afef`，而主按钮在 One Dark Pro 里本来就是灰的（`#404754`）。表的每一块都注明了取自哪个官方键，可以直接拿官方文件核对。**唯一不取绝对值的是「叠加型」令牌**（hover、按下、选中、ghost 这类由宿主决定底色的状态）：它们用半透明白叠加，因为宿主不会告诉我们某一行的底色是画布、面板还是抬起的卡片，绝对值只能在其中一种上成立。卡片预览的排布与主题清单的形式参考了 [mux9056-bot/dsh-theme](https://github.com/mux9056-bot/dsh-theme)（Apache-2.0）。
