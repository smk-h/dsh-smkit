本文说明 dsh-smkit 的「MCP 调试」页：把 [MCP Inspector](https://github.com/modelcontextprotocol/inspector) 最核心的那一屏搬进 dsh —— 选一台已连接的服务器，选一个工具，填参数，看服务器原样返回的内容和它推过来的通知。

## 一、 它解决什么

设置 → MCP 里能看到「这台服务器有几个工具、参数长什么样」，但看不到**调用一次会返回什么**。想验证一个工具，过去只有两条路：

- 让模型调一次：花一轮 token，结果还要从工具卡片里翻；
- 用 `/mcp call`：不花 token，但参数要手写 JSON，结果是纯文本，图片、通知、耗时都看不到。

这两条路都缺同一件事：**像 Inspector 那样把请求和响应并排摆着看**。调试设备类 MCP 时这一点尤其重要——`serial_exec` 返回的是一整段设备日志，`session_id` 用错时服务器给的是它自己的错误文本，人需要看到原文而不是被投影过的文本。

本页因此不改配置、不接管会话，只做三件事：列服务器、列工具、发一次 `tools/call`。

## 二、 页面在哪

主面板，不是设置弹窗：左侧栏（会话列表那一列）底部图标区多一枚「虫子」图标，点它整个中间区域切换成调试页，就像「记忆系统」那样。再点一次会话就切回去。

为什么不做成 `设置 → MCP` 的一个标签页：三栏（服务器 / 工具 / 结果）在设置弹窗的宽度里挤不下，而 Inspector 的价值有一半来自「同时看见三栏」。

## 三、 三栏各是什么

### 1. 左栏：服务器

按作用域分组，顺序与设置页一致：先是全局，再是各工作区（分组标题是工作区目录名，悬停可看完整路径）。

每行显示状态色点、服务器名、工具数量、状态文字。状态文字用的是宿主自己的词汇（已连接 / 连接中 / 重连中 / 待认证 / 错误 / 未连接 / 已禁用 / 冲突 / 已配置），与设置页同一套。

选中一台后，下方是它的传输事实：

| 字段 | 内容 |
| --- | --- |
| 类型 | `stdio` / `HTTP` |
| 命令 | stdio 的 `command` + `args` 拼成一行；HTTP 显示 URL |
| 工作目录 | stdio 的 `cwd`（配置了才有） |
| 环境变量 | 只列**变量名**，不显示值 |
| 服务器 | 握手时服务器自报的 `serverInfo.name` · `version` |
| 错误 | 连接错误原文（有错才有） |

两个动作：**重启**、**断开**。两者调的都是设置页那一对路由（`POST /servers/:id/restart`、`/stop`），语义完全一样——重启会重建传输，断开只关连接、保留配置。服务器未连接时页面会说明「工具列表为空是因为它没连上」，而不是让人对着空列表猜。

### 2. 中栏：工具与历史

工具列表来自该服务器的 `tools/list` 快照，显示的是**服务器声明的原始名字与描述**——不是模型看到的 `mcp__<服务器>__<工具>`。调试时你要知道该向服务器要哪个名字。

- 搜索框按名字与描述做子串匹配（不分大小写）；
- 「刷新」立即重读一次 `/servers` 与 `/workspaces`（页面本身每 3 秒也会自动读一次，与设置页同频）；
- 描述最多两行，超出省略：一条工具描述不能占掉五行把其余三十条挤走。

下方「历史」是**本次挂载**内的调用记录（最多 25 条，最新在最上），每条记工具名、成功/失败、耗时、时间。点一条把它当时的返回值原样调回右栏——这是终端 dump 做不到的事。

### 3. 右栏：工具详情

**参数**有两种编辑模式：

| 模式 | 适用 | 控件 |
| --- | --- | --- |
| 表单 | 看得清有哪些参数 | 每个声明参数一行：名字、类型、必填标记、描述，下面按类型给控件 |
| JSON | 从别处粘贴一整个对象 | 一个多行文本框，内容是完整的 `arguments` 对象 |

表单里每种类型对应的控件与转换规则：

| schema | 控件 | 提交时的值 |
| --- | --- | --- |
| `string` | 文本框 | 原样字符串 |
| `number` / `integer` | 数字框 | 数字；非数字、非整数按类型拒绝 |
| `boolean` | `未设置 / true / false` | 布尔 |
| `enum` | 下拉框（含「未设置」） | 命中的那一个成员，保持原类型 |
| `object` / `array` | 多行框 | `JSON.parse` 的结果 |
| 无类型（`any`/`oneOf`） | 文本框 | 能解析成 JSON 就用 JSON，否则当字符串 |

规则只有一条值得记住：**留空等于不发送**。必填项留空时页面直接拒绝（不发请求），可选项留空则整个字段不进 `arguments`——发出 `""` 是另一个请求。

两个模式共用同一份状态：切到 JSON 时把当前表单内容序列化进去，切回表单时按字段名回填。不会因为切模式丢输入。

**运行工具**把 `{ id, tool, arguments }` POST 到 `/smkit/api/debug/call`。结果区分三种：

| 结果 | 界面 | 含义 |
| --- | --- | --- |
| 成功 | 绿色「成功」+ 耗时 | JSON-RPC 请求成功，服务器返回 `isError` 不为 `true` |
| 失败 | 红色「失败」+ 耗时 | 服务器把工具报错了（`isError: true`），或者传输层失败（超时、子进程死了、连接被拒）；前者连 `content` 一起显示，后者显示错误原文 |
| 未发送 | 灰色「未发送」 | 页面自己拒绝的（必填缺失、数字不合法、JSON 不合法），请求根本没出去 |

结果的显示分两层：**内容**按服务器给的 content block 渲染（文本用 `<pre>`、图片用 `<img>`、其他类型打印 JSON），**原始 JSON** 折在下面——两者都留，是因为投影后的文本会藏掉人真正要看的字段。

**服务器通知**是这一页独有的东西：服务器主动推的帧（`notifications/message`、`tools/list_changed`、progress……）在宿主里原本只被消费一种（工具列表变化），其余全部丢弃。本功能在传输层把每一帧记进一个按服务器的环形缓冲，页面读出来显示。展开任一帧可看它的 `params`；参数超过 8 KB 的帧只留方法名并标注「参数过大，已省略」，不塞一个看起来完整的截断体。

## 四、 数据从哪来

| 用途 | 路由 | 说明 |
| --- | --- | --- |
| 服务器 + 工具 + 状态 + 服务器自述 | `GET /smkit/api/servers`、`GET /smkit/api/workspaces` | 与设置页同一对接口，**不新增** |
| 调一次工具 | `POST /smkit/api/debug/call` | 新增；body `{ id, tool, arguments }` |
| 读通知 | `GET /smkit/api/debug/notifications?id=<服务器 id>` | 新增 |
| 清通知 | `POST /smkit/api/debug/notifications/clear` | 新增；body `{ id }` |

`id` 是服务器的**全局唯一 id**（工作区服务器是 `ws-` 开头的确定性 id），因此一个 id 就能定位到全局或任一工作区的服务器，不需要再带作用域。

调用落在**同一个活连接**上：`tools/call` 直接发给模型调用的那条传输。这是关键——设备类 MCP 的串口 / SSH 会话在服务器进程里，另起一个 inspector 进程连同一个命令，连到的是另一个实例，调试的不是同一个东西。

超时沿用「设置 → MCP → 高级」里的工具调用超时（默认 60 秒），每次请求现读，改完不需要重连。

## 五、 不做什么

| 不做 | 原因 |
| --- | --- |
| 增删改服务器配置 | 那是设置页的事；一页两用会让人不敢点 |
| Resources / Prompts 面板 | 本插件只维持 `tools/*` 与 `initialize` 的传输面；`resources/list`、`prompts/list` 需要通用 `request()`，而 HTTP 传输不暴露它 |
| 临时连接一个不入库的服务器 | 同上：临时连接等于再写一套传输生命周期与凭证处理，与「调试已配置的服务器」是两件事 |
| 回放历史到磁盘 | 历史只活在这次挂载里；跨刷新恢复一个「选中的服务器」会让人误判当前连的是谁 |
| 采样 / elicitation / roots | 宿主不发起这些请求，页面没有可展示的东西 |

## 六、 已知限制

| 项 | 限制 |
| --- | --- |
| 主面板 id | `smkit-mcp-debug`；与左栏图标的条目 id 必须一致，否则页面在但点不开 |
| 工作区服务器 | 只在「有 agent 打开过该工作区」时才真正连接；未打开的工作区里显示的服务器状态是「已配置」，工具列表为空 |
| 通知条数 | 每台服务器保留最近 50 条，超出丢最旧 |
| 历史条数 | 本次挂载最多 25 条 |
| 图片结果 | 以 `data:` URL 直接渲染；特大图片会让 DOM 变大，页面不做缩放或下载 |
| 服务器名 | 显示服务器自己声明的名字：全局用配置名，工作区用配置名；两者可能同名不同源（工作区重名规则允许），以分组区分 |
